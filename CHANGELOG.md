# Changelog

## Unreleased

### Added

- Local research across followed YouTube channels, with saved caption evidence, dated comparisons, stock aliases and independent statement reviews.
- TXT/SRT/VTT imports and original-source citations with retained timestamps.
- Urdu and English reading controls, explicitly requested YouTube captions and Ollama Cloud translation.
- Original-transcript retrieval and stock aliases, with at most one cloud synthesis request per uncached expert answer.
- Backed-up maintenance previews and transactional repairs that preserve human decisions and original automatic payloads.
- MIT licensing, contributor/security guidance, isolated browser checks and dependency monitoring for npm and GitHub Actions.

### Fixed

- Numeric caption lines and WebVTT metadata parsing, Hindi action/negation handling, signed financial-number checks and stock attribution within the supporting quote.
- Duplicate review counting across overlapping original evidence, translation-job scope validation.
- Worker restart recovery and research-answer cache invalidation.
- Cross-site GET requests reaching provider-backed endpoints; removed unused cloud planning/reranking paths.

### Removed

- Python/IndicTrans2 model translation, automatic question translation and derived English retrieval. No Python installation or model download is required. YouTube and Ollama remain explicit choices.
- Background local translation preparation and model evaluation tools. Existing records, human reviews and installed private files are preserved; pending local jobs are retired. Cross-language search recall may be lower.

### Remaining validation

- Independent review of thirty real source passages and the twenty-question evidence evaluation are pending; synthetic tests do not establish financial accuracy.
- YouTube caption availability and provider quotas vary. No model weights, provider credentials, collected transcripts or personal research data are distributed.
